# Հայկական լրատվական Telegram բոտ

Ամեն 15 րոպեն մեկ GitHub-ը ավտոմատ գործարկում է `bot.py`-ը.
1. վերցնում է նոր նյութերը `sources.json`-ի աղբյուրներից (կայքերի RSS և հանրային Telegram կանալներ),
2. բաց է թողնում արդեն եղածները և կրկնվող լուրերը,
3. Claude-ով վերաշարադրում է կարճ գրառման (եթե API key չկա, դնում է վերնագիրն ու սկիզբը),
4. հրապարակում է մեր կանալում նկարով և աղբյուրի հղումով։

Առաջին գործարկման ժամանակ ոչինչ չի հրապարակում, միայն «հիշում է» եղած լուրերը, որ կանալը չլցվի հին նյութերով։

## Կարգավորում (մեկ անգամ)

### 1. Telegram բոտ և կանալ
1. Telegram-ում գրեք **@BotFather**-ին → `/newbot` → անուն տվեք → կստանաք **token** (`123456:ABC...`)։
2. Ստեղծեք կանալը (Public, օրինակ `@orvalur`)։
3. Կանալի Settings → Administrators → ավելացրեք ձեր բոտը, որ կարողանա **Post messages**։

### 2. GitHub
1. Ստեղծեք **Public** repo (Public-ի համար Actions-ն անսահմանափակ անվճար է, Private-ի համար ամսական 2000 րոպե է, որը 15 րոպեանոց ռեժիմին չի բավականացնի)։ Գաղտնի բանալիները public repo-ում էլ չեն երևում։
2. Վերբեռնեք այս թղթապանակի ֆայլերը։
3. Repo → **Settings → Secrets and variables → Actions**:
   - **Secrets** ներդիր.
     - `TELEGRAM_BOT_TOKEN` — BotFather-ի token-ը
     - `ANTHROPIC_API_KEY` — console.anthropic.com-ից (ցանկության դեպքում, առանց դրա էլ կաշխատի)
   - **Variables** ներդիր.
     - `TELEGRAM_CHANNEL` — `@orvalur`
     - `SIGNATURE` — ըստ ցանկության, օրինակ `👉 @orvalur`
     - `MODEL` — ըստ ցանկության (տե՛ս ստորև)
     - `MAX_POSTS_PER_RUN` — 15 րոպեում առավելագույնը քանի գրառում (ըստ նախնականի՝ 3)
     - `MIN_GAP_MINUTES` — գրառումների միջև նվազագույնը քանի րոպե (ըստ նախնականի՝ 3, գումարած պատահական 0–2 րոպե)

### 3. Փորձարկում
Repo → **Actions → news → Run workflow** → `dry_run` = `1`։ Log-ում կտեսնեք, թե ինչ գրառումներ կհրապարակեր, առանց իրական հրապարակման։
Հետո նույնը `0`-ով, և այնուհետև ամեն ինչ աշխատում է ավտոմատ։

## Աղբյուրներ ավելացնել կամ անջատել
`sources.json` ֆայլում.
```json
{ "name": "Անուն", "type": "telegram", "channel": "kanal_username" }
{ "name": "Անուն", "type": "rss", "url": "https://site.am/rss" }
```
`"enabled": false` դնելով աղբյուրն անջատվում է։ Telegram կանալը պետք է լինի հանրային, և `t.me/s/<անուն>` էջը պետք է բացվի։

## Ծախս
- GitHub Actions՝ անվճար (public repo)։
- Claude վերաշարադրում (մոտ 60 գրառում օրական).
  - `claude-opus-5-5` (նախնական, ամենալավ որակը)՝ մոտ $10–20 ամսական
  - `claude-haiku-5-5` (դրեք `MODEL` variable-ում)՝ $1-ից պակաս ամսական, որակը մի փոքր ցածր է
- Առանց `ANTHROPIC_API_KEY`-ի՝ $0, բայց տեքստը վերաշարադրված չի լինի։

## Կարևոր
Ուրիշի տեքստը բառացի կրկնելը կարող է բողոքների պատճառ դառնալ։ Դրա համար բոտը տեքստը վերաշարադրում է և միշտ դնում աղբյուրի հղումը։ Հնարավորության դեպքում խոշոր աղբյուրներից թույլտվություն վերցրեք։
